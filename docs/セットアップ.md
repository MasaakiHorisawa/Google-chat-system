# セットアップ(Google Chat アプリ)

認証情報(鍵ファイル・認証 JSON)はこのリポジトリに置かない。設定値はスクリプト プロパティに入れる。

## 1. Apps Script プロジェクトを作る
1. script.google.com で新しいプロジェクトを作る(議事録システムとは別のプロジェクト)。
2. 「プロジェクトの設定」→「appsscript.json マニフェスト ファイルをエディタで表示する」をオンにする。
3. `gas/` の `appsscript.json`・`Chat.gs`・`Shared.gs` の中身をそれぞれ貼る(clasp を使うなら rootDir を `gas` にする)。

## 2. スクリプト プロパティ
「プロジェクトの設定」→「スクリプト プロパティ」に入れる。

| キー | 値 | |
|---|---|---|
| `MASTER_SS_ID` | 議事録システムのマスタースプレッドシートの ID(URL でも可) | 必須 |
| `ALLOWED_DOMAIN` | 事務所のドメイン(例 `example.co.jp`)。これ以外のアカウントには返さない | 任意(推奨) |

エディタで `checkSetup` を実行し、ログに「マスター: … / 関与先 N件」と出れば読めている。

## 3. Google Cloud と Chat API
1. 「プロジェクトの設定」→「Google Cloud Platform(GCP)プロジェクト」で、標準の Cloud プロジェクトに切り替える。
2. その Cloud プロジェクトで Google Chat API を有効にし、「構成」を開く。
   - アプリ名・アバター・説明を入れる。
   - 機能: 「1:1 のメッセージを受信する」「スペースとグループの会話に参加する」。
   - 接続設定: 「Apps Script プロジェクト」にして、デプロイ ID を入れる(試すときは「デプロイ」→「デプロイをテスト」の Head deployment ID、本番は版付きのデプロイ ID)。
   - 「Google Workspace アドオンとしてビルド」の選択肢が出たら外す(このコードは従来形式のイベントを受ける)。
   - 公開範囲: 事務所内の特定のユーザー/グループだけにする。
3. Chat でアプリを DM に追加し、`ヘルプ` と送る。初回は各自が承認する(その人の権限で読むため)。

## 4. 使い方
```
ノート サンプル商事
質問 1234-5678
ルール サンプル商事
```
`ルール` の返事のコードブロックをコピーして、MF 作業用の Claude に貼る。長すぎて Chat に収まらないときは、議事録システムのパネル →「カルテ登録」→「Claudeにルールを渡す」を使う。

## 議事録システムを更新したとき
議事録システムの Code.gs の版が上がったら、`node tools/sync.js check <Code.gs>` を実行する。不一致なら `pull` してテストし、Apps Script の `Shared.gs` を貼り替える。
