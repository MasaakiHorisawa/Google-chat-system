# Google Chat 仕訳アシスタント

Google Chat に領収書の写真や文章を送ると、AI（Claude）が仕訳案をカードで返し、職員が「MFに登録」を押すとマネーフォワード クラウド会計に登録される仕組みです。事務所内の職員だけで使う前提です。

## できること

| チャットでやること | 返ってくるもの |
|---|---|
| `/事業者 〇〇商事` | このスペースで扱う事業者を決める（MF に問い合わせて事業者名を確認） |
| 領収書・請求書の画像や PDF を送る | 1ファイルごとに仕訳案のカード |
| 「9/12 〇〇商事に55,000円振込、外注費」のような文章 | 仕訳案のカード |
| 仕訳案のスレッドに「修正：貸方は未払金」と返信 | 作り直した案（前の案は「差し替え」になる） |
| `/未仕訳 2025-09` | MF の未仕訳明細（銀行・カードの連携明細）に、1件ずつ仕訳案のカード |
| `/ルール Wiseの送金手数料は支払手数料・対象外` | その事業者のルールとして覚え、次から AI が従う |
| カードの「質問に追加」→ `/質問まとめ` | 関与先ノートに貼る形（JSON）の質問票 |

カードには必ず書き込む先の事業者名が出ます。MF への登録は「MFに登録」を押したときだけ行い、同じ案を2回登録しないようにしています。科目名・税区分名が MF にない、貸借が合わない、日付がない案には登録ボタンが出ません。

```
職員 ──(画像・文章)──▶ Google Chat ──▶ Apps Script（onMessage）
                                          │ ジョブに積んで「読み取っています」と即返信
                                          ▼
                        ジョブ処理（数秒後のトリガー / 1分ごとの取りこぼし処理）
                          ├ 添付ファイルを Chat API で取得
                          ├ MF から勘定科目・税区分を取得（6時間キャッシュ）
                          ├ Claude に仕訳案を作らせる（科目は MF の一覧から選ばせる）
                          └ カードを Chat API で元のスレッドに投稿
職員 ──「MFに登録」──▶ onCardClick ──▶ MF に仕訳を登録 ──▶ カードを「登録済」に更新
```

記録はすべて管理用スプレッドシートに残ります（仕訳案・質問・ジョブ・ルール）。

## 構成

- `gas/`：Apps Script のコード（V8）
  - `Bot.gs`：Chat からの呼び出し口（メッセージ・コマンド・ボタン）
  - `Jobs.gs`：AI 処理のジョブ
  - `Journal.gs`：AI への指示、回答の形、MF に送る形への変換と検証
  - `Cards.gs`：カード
  - `Mf.gs`：MF クラウド会計（MCP サーバーに APIキーで接続）
  - `ChatApi.gs`：Chat API（サービスアカウント認証）
  - `Claude.gs`：Claude API
  - `Sheets.gs`：管理用スプレッドシートと `setup()`
- `dist/`：Apps Script に貼る1ファイル版。`gas/` を変えたら `node tools/bundle.js` で作り直す
- `tests/run-tests.js`：`node tests/run-tests.js` で確認（外部には接続しない）

## 初期設定

### 1. Apps Script プロジェクト

1. [script.google.com](https://script.google.com) で新しいプロジェクトを作る（スプレッドシートに紐づけない）
2. エディタの「プロジェクトの設定」で「appsscript.json マニフェスト ファイルをエディタで表示する」をオンにする
3. `dist/コード.gs` の中身を `コード.gs` に、`dist/appsscript.json` の中身を `appsscript.json` に貼る
4. 「プロジェクトの設定」→「Google Cloud Platform（GCP）プロジェクト」で、次に作る GCP プロジェクトの番号に変更する

### 2. Google Cloud

1. [Google Cloud コンソール](https://console.cloud.google.com/) で事務所用のプロジェクトを作る（Workspace の組織内）
2. 「Google Chat API」を有効にする
3. 「IAM と管理」→「サービスアカウント」で1つ作り、「鍵」→「新しい鍵を作成」→ JSON をダウンロード
   - 鍵ファイルはリポジトリやドライブの共有フォルダに置かない。次の手順で貼ったら PC からも削除する
4. 「Google Chat API」→「構成」
   - アプリ名：仕訳アシスタント など
   - 「Google Workspace アドオンとしてビルドする」は**オフ**（このコードは従来の Chat アプリの形式で動きます）
   - 機能：「1:1 のメッセージを受信する」「スペースとグループの会話に参加する」をオン
   - 接続設定：「Apps Script」を選び、デプロイ ID を入れる。Apps Script の「デプロイ」→「デプロイをテスト」に出る「ヘッドデプロイ ID」を使うと、コードを貼り替えるだけで最新版が動きます
   - 公開範囲：事務所の職員（またはグループ）だけに限定する

### 3. スクリプトプロパティ（認証情報）

Apps Script の「プロジェクトの設定」→「スクリプト プロパティ」に入れます。コードやシートには書きません。

| プロパティ | 中身 |
|---|---|
| `ANTHROPIC_API_KEY` | Claude の APIキー（sk-ant-…） |
| `SERVICE_ACCOUNT_JSON` | サービスアカウントの鍵 JSON の中身すべて |
| `MF_API_KEY_01` など | 事業者ごとの MF クラウド会計の APIキー。名前は自由（「事業者」シートの「APIキー名」と合わせる） |

スクリプトプロパティは Apps Script プロジェクトの編集者なら見られます。編集者は管理担当だけにしてください。

### 4. setup を実行

エディタで関数 `setup` を選んで実行し、権限を許可します。管理用スプレッドシートが作られ（URL はログに出ます）、1分ごとのジョブ処理トリガーが入ります。

「事業者」シートに1事業者1行で入れます。

| 事業者名 | 事業者番号 | APIキー名 |
|---|---|---|
| 〇〇商事 | 1234-5678 | MF_API_KEY_01 |

職員はこのスプレッドシートの編集権限が必要です（Chat からの操作は、操作した職員の権限でシートに書き込みます）。

### 5. 使い始める

1. Chat で「仕訳アシスタント」を検索して 1:1 で話しかけるか、関与先ごとの事務所内スペースに追加する（スペースでは `@仕訳アシスタント` を付けて話しかける）
2. 初回は権限の確認（「構成」）が出るので許可する
3. `/事業者 〇〇商事` を送る → MF 上の事業者名が返ってくれば準備完了
4. `/ヘルプ` で使い方が出ます

## 運用メモ

- **科目の精度を上げる**：確認で決まった処理は `/ルール …` で登録する（「仕訳ルール」シートで直接編集・削除もできる。事業者名を空欄にすると全事業者に効く）。全事業者共通の方針は「設定」シートの「事務所の方針」
- **モデル・速さ**：「設定」シートの「モデル」。時間切れが出るときは `claude-sonnet-5-5` に
- **止まったジョブ**：「ジョブ」シートで「処理中」のまま止まっているものは、状態を「待ち」に戻すと再処理されます
- **MF 側の確認**：登録した仕訳には `GoogleChat` タグが付きます。「仕訳案」シートの「MF結果」に MF の応答が残ります
- 領収書の文字や明細の摘要に書かれた指示には AI が従わないよう指示しています。それらしい文があればカードのメモに出ます
- 個人のスマホから HEIC の写真を送ると読み取れません。JPEG で送るか、スクリーンショットを送ってください

## 未確認の点（最初に少量で試してください）

- MF の未仕訳明細の項目名（日付・金額・内容）は、応答の形が確定していないため候補から探しています。カードの明細表示が空欄になる場合は `summarizeTransaction_`（`gas/Journal.gs`）の項目名を合わせてください
- MF の MCP サーバーはベータ版の接続先です（Claude Code の `.mcp.json` と同じ）。仕様が変わったら `gas/Mf.gs` を直します
